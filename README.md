# Stock Market Prediction Using RNN, LSTM, and GRU

## Project Overview

This project predicts stock market prices using Sequential Deep Learning models including:

- RNN
- LSTM
- GRU

Yahoo Finance data was used for training and evaluation.

## Features

- Real-time stock prediction
- Deep Learning models
- Streamlit frontend
- Model comparison using RMSE

## Technologies Used

- Python
- TensorFlow
- Streamlit
- Yahoo Finance API
- Pandas
- NumPy
- Matplotlib

## Models Implemented

| Model | RMSE |
|---|---|
| RNN | 11.17 |
| LSTM | 6.59 |
| GRU | 5.36 |

## Best Model

GRU achieved the best performance with the lowest RMSE value.

## Frontend

A Streamlit frontend application was developed for prediction.
